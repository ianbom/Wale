# Tangkoko tour frontend

English frontend reproduction of the Sulawesi.com Tangkoko tour page.

```bash
npm install
npm run dev
```

Open `http://localhost:3000` or `/en/703qix0x6`.

```bash
npm run lint
npm run build
npm start
npm test
```

The smoke check requires a running server. Set `TEST_ORIGIN` to check another port.
Photo, vector, and font assets match the publicly accessible reference. Font licenses are in `public/fonts`. Navigation outside this single-page clone links to the reference site. No booking backend, analytics, or affiliate scripts are included.
